# Conversation Mirror

Analyze the current conversation record chronologically and infer how the user's thinking and interaction patterns changed from beginning to end.

This analysis is not a diagnosis of the user's actual personality, ability, or mental state.  
It is a limited inference based only on observable changes in the conversation text.

## Cautions

- Do not make definitive claims about the user's personality or psychological state.
- Use only changes observable in the conversation text.
- Provide evidence ranges or conversation sections for each major claim.
- Analyze not only development, but also repetition, bias, limitations, and the influence of AI responses.
- Separate user-generated change from AI-assisted organization.
- Do not count a well-structured AI summary as direct evidence of the user's independent development unless supported by the user's own questions, revisions, decisions, or artifacts.

## Analysis Axes

1. Changes in topics of interest
2. Changes in problem definition
3. Changes in abstraction level
4. Changes in question quality
5. Changes in evidence and verification demands
6. Changes in AI usage
7. Changes in self-awareness and metacognition
8. Changes in decision-making patterns
9. Changes in language density and expression
10. Remaining limitations and repeated patterns

## Development Level Model

Evaluate the user's changes using the following 5-level model.

### Level 1. Information Seeker

The user asks for simple facts, summaries, or explanations.

### Level 2. Problem Solver

The user asks for solutions, comparisons, recommendations, or practical help with a specific problem.

### Level 3. Structure Analyst

The user asks about variables, causes, mechanisms, system structure, or hidden constraints.

### Level 4. Hypothesis Tester

The user presents their own ideas and asks for objections, verification, alternative explanations, or scenario testing.

### Level 5. Thought Designer

The user works with AI to design frameworks, decision structures, research directions, prompts, systems, or long-term strategies.

For each time period, estimate which level the user is closest to.  
Do not force a single fixed score. Explain differences by domain or task type.

## Output Structure

[1] One-sentence summary  
[2] Chronological change map  
[3] Analysis table by axis  
[4] Strongest development hypothesis  
[5] Three alternative hypotheses  
[6] Parts where AI responses may have made the user appear to change  
[7] Abilities that actually appear to have strengthened  
[8] Remaining weak points  
[9] Next development coordinate  
[10] Overall confidence and limitations
